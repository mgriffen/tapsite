Extract a design system.
Hand it to Claude Design.

You need a deck, a prototype or a one-pager that matches a brand. Nobody can find the design files, and the person who made them left. The brand does still exist in one place: the rendered website.

worked example subject stripe.com captured 2026-08-11 tapsite v5.2.0

Every block of output on this page is real. It was captured by running the commands shown against the live site on the date above, and pasted here unedited. Re-run them and you will get the same shape, though the counts will have moved.

01Extract the design system

Point tapsite at the URL. It renders the page in Chromium and reads computed styles — the values the browser actually resolved, not what the stylesheet hoped for.

$ npx -y tapsite --profile design # then, from your agent: # "extract the colour palette and fonts from https://stripe.com"
{ "_meta": { "tool": "tapsite_extract_colors", "url": "https://stripe.com/", "timestamp": "2026-08-11T06:41:47.458Z", "version": "5.2.0", "description": "Color palette extracted from computed styles and CSS custom properties" }, "colors": [ { "hex": "#533afd", "rgb": "rgb(83, 58, 253)", "count": 5121, "samples": ["a.hds-link (color)", "a.hds-link (border-color)"] }, … ] }

Note the samples field. Every value carries the selectors it was found on, so a colour is not just a hex — it is evidence of where the brand uses it.

03Audit it before you propagate it

You are about to copy this palette into everything your team produces. Worth ten seconds to check it first.

Contrast (WCAG AA): 13 passing, 3 failing out of 16 pairs Worst: #ffffff/#ffffff = 1:1, #81b81a/#ffffff = 2.39:1, #ff6118/#ffe0d1 = 2.41:1

tapsite_extract_contrast · stripe.com · 2026-08-11 · sampleSize 200

One of those three is not real, and that is the interesting part

#ffffff/#ffffff = 1:1 is white text on white background, which nobody shipped. It is the signature of a text element sitting on an image or gradient: the checker walks up the DOM looking for a background-color, finds none because the background is a picture, falls through to the body, and reports white.

Every contrast tool that reads computed styles has this hole. It fails in the dangerous direction too — the same blind spot will pass white text over a light photograph at a true 3.5:1.

The fix is to stop asking the DOM and look at the pixels: screenshot the page, screenshot it again with the text hidden, and read the brightest pixel inside each text box. That is the true worst case, and it is what tapsite_audit falls back to when the background is not provably solid.

The other two are ordinary and worth knowing about before you build a deck on them — a green on white at 2.39:1 and an orange on pale peach at 2.41:1. Both are below the 4.5:1 AA threshold for body text.

04Hand it to Claude Design

tapsite extracts a design system. Claude Design applies one to everything it makes. That is the whole composition.

# tapsite writes W3C design tokens $ npx -y tapsite --profile design # "export the design system for https://stripe.com" # -> design-tokens.json (W3C format) # -> design-tokens.css (paste-ready :root block) # -> report.html (visual)
:root { --color-brand: #533afd; /* 5121 uses */ --color-ink: #000000; /* 7464 uses */ --color-ink-muted: #50617a; /* 1176 uses */ --color-surface: #ffffff; /* 952 uses */ --color-ink-deep: #061b31; /* 939 uses */ --font-family-base: sohne-var; --font-size-body: 16px; /* 582 uses */ }

shape of design-tokens.css · values captured 2026-08-11

Load those into a Claude Design project and every deck, prototype and one-pager it produces comes back on-brand — without anyone eyedropping a screenshot or guessing at the type scale.

The counts survive into the comments on purpose. Six months later they are how you tell the brand colour from a colour that merely appeared once.

05Re-run it when the brand moves

Brands change without telling their vendors. Snapshot the extraction now and diff it later; drift shows up as a list rather than a vague sense that the deck looks off.

# same URL, two points in time $ npx -y tapsite # "diff https://stripe.com against the snapshot from August"

The same command answers the competitive version of the question — point it at two different sites instead of one site twice.

06Reproduce this page

Nothing above was hand-written. Run it yourself:

$ npx -y tapsite --profile design

Then ask your agent for the colour palette, the fonts, and a contrast audit of any URL. Output lands as JSON on disk with a _meta block recording the tool, the URL, the timestamp and the version — so a number in a document can always be traced back to the run that produced it.
